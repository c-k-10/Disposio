Disposio herunterladen

Desktop-App für Windows 10/11 (x64) · Version {Version}

1. Zertifikat installieren (einmalig je PC)

Disposio ist mit einem eigenen Zertifikat signiert. Windows installiert die App erst, wenn es diesem Zertifikat vertraut.

Zertifikat herunterladen
  1. Disposio.cer doppelklicken → Zertifikat installieren…
  2. Speicherort: Lokaler Computer → Weiter (Administrator-Abfrage mit Ja bestätigen)
  3. Alle Zertifikate in folgendem Speicher speichern → Durchsuchen → Vertrauenswürdige Personen → OK
  4. Weiter → Fertig stellen

2. App installieren

Disposio herunterladen
  1. Die heruntergeladene Datei Disposio_x64.appinstaller doppelklicken.
  2. Im Fenster „App-Installer“ auf Installieren klicken.

Updates kommen danach von selbst: Beim Start fragt Disposio nach einer neuen Version.

3. Datenbank-Zugang einrichten

Disposio braucht die Windows-Benutzervariable DISPOSIO_CONNECTION_STRING. Den Wert gibt es vom Team, nicht auf dieser Seite. Danach Disposio neu starten.

Probleme?

  1. „Das Zertifikat des Herausgebers konnte nicht überprüft werden“: Schritt 1 fehlt oder das Zertifikat liegt im falschen Speicher. Wichtig sind „Lokaler Computer“ und „Vertrauenswürdige Personen“.
  2. Der Browser warnt beim Herunterladen: „Behalten“ wählen.
  3. Das Fenster „App-Installer“ bleibt leer: schließen und die Datei noch einmal öffnen.
